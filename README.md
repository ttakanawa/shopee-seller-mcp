# Shopee Seller MCP

An unofficial, open-source stdio MCP server for the Shopee Open Platform API.
This project is not affiliated with or endorsed by Shopee.

The server exposes individual API endpoints as typed MCP tools. Consult the
[Shopee Open Platform documentation](https://open.shopee.com/documents) for
current API rules and account permissions.

Read tools are enabled by default. Business and credential mutations require
an explicit operator allowlist. Available APIs depend on your Shopee account
permissions and region.

the CLI also needs the shop ID and authorization verification value from it.
